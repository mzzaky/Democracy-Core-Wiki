### 🏛️ Government Placeholders

#### President Information
| Placeholder | Description | Example Output | Return Type |
|------------|-----------|---------------|-------------|
| `%democracy_president%` | Current president's name | `Steve` or `None` | String |
| `%democracy_term_time%` | Remaining term duration | `15d 5h 30m` | String (formatted) |
| `%democracy_approval_rating%` | President's approval rating (1-5) | `4.2` | Decimal |
| `%democracy_consecutive_terms%` | Number of consecutive terms | `2` | Integer |
| `%democracy_salary_payouts%` | Total salary payouts this period | `1500000.00` | Decimal |
