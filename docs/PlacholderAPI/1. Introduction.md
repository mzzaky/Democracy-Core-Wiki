
## 📖 Introduction

DemocracyCore provides complete integration with **PlaceholderAPI**, allowing you to display government data, elections, player statistics, treasury, and arena data in other plugins such as scoreboards, chat, tab lists, and holograms.

### Key Features
- **40+ placeholders** covering all aspects of the plugin
- Real-time support for government and election data
- Comprehensive player statistics
- Detailed treasury data
- PvP arena statistics

---

## ⚙️ Requirements

### Required Plugins
1. **PlaceholderAPI** v2.11.6 or newer
2. **Vault** v1.7 or newer (for economy)
3. **DemocracyCore** v1.3.0 or newer

### Compatibility
- **Minecraft**: 1.21+
- **Server**: Paper/Spigot
- **Java**: 21+

---

## 🔧 Installation

### Step 1: Install PlaceholderAPI
```bash
# Download from SpigotMC or use in-game command:
/papi ecloud download PlaceholderAPI
```

### Step 2: Verify Installation
After server restart, check logs for confirmation:
```
[DemocracyCore] PlaceholderAPI found! Registered placeholders.
```

### Step 3: Test Placeholders
```
/papi parse me %democracy_president%
```
