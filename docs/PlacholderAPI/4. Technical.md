## 🔧 Technical Implementation

### System Architecture

```
DemocracyCore
    │
    ├─ DemocracyExpansion (PlaceholderAPI Expansion)
    │   ├─ onRequest(OfflinePlayer, String params)
    │   │   ├─ Government Data
    │   │   ├─ Election Data
    │   │   ├─ Treasury Data
    │   │   └─ Player Data
    │   └─ formatTime(long millis)
    │
    └─ Managers
        ├─ GovernmentManager
        ├─ ElectionManager
        ├─ TreasuryManager
        └─ DataManager
```

### Registration Code

```java
// DemocracyCore.java - onEnable()
if (Bukkit.getPluginManager().getPlugin("PlaceholderAPI") != null) {
    new id.democracycore.placeholders.DemocracyExpansion(this).register();
    getLogger().info("PlaceholderAPI found! Registered placeholders.");
}
```

### Custom Expansion Class

File: `id/democracycore/placeholders/DemocracyExpansion.java`

```java
public class DemocracyExpansion extends PlaceholderExpansion {
    
    @Override
    public String getIdentifier() {
        return "democracy";  // %democracy_xxx%
    }
    
    @Override
    public String onRequest(OfflinePlayer player, String params) {
        // Parsing logic for each placeholder
        // Return null if placeholder is not found
    }
}
```

### Performance Optimization

1. **Caching**: All data is cached in memory by DemocracyCore
2. **Fast Lookup**: Uses HashMap for O(1) lookup
3. **Lazy Loading**: Player data is only loaded when needed
4. **Async Safe**: Placeholders can be called from any thread

## 🐛 Troubleshooting

### Issue: Placeholders Not Working

**Symptoms**: Placeholder displays `%democracy_xxx%` without being parsed

**Solution**:
```bash
# 1. Check if PlaceholderAPI is installed
/plugins

# 2. Check if DemocracyCore is registered
/papi list
# 'democracy' should be in the list

# 3. Manual test
/papi parse me %democracy_president%

# 4. Reload PlaceholderAPI
/papi reload
```

### Issue: Data Not Updating Real-time

**Symptoms**: Placeholders display old data

**Solution**:
- Data is retrieved directly from managers, so it should be real-time
- If still problematic, restart the server
- Check logs for errors

### Issue: Player Placeholder is Null

**Symptoms**: Player-specific placeholder returns "None" or "0"

**Cause**:
- Player does not have stored data yet
- Player is offline when accessed

**Solution**:
```java
// Ensure player is online
%democracy_is_president%  // Will return "No" if data is missing

// Or use global placeholders
%democracy_president%  // Does not require player context
```

### Debug Mode

For debugging, add logs in `DemocracyExpansion.java`:

```java
@Override
public String onRequest(OfflinePlayer player, String params) {
    // Debug log
    plugin.getLogger().info("Placeholder requested: " + params + " for player: " + 
                           (player != null ? player.getName() : "null"));
    
    // ... rest of code
}
```
