# Overview

## ⚙️ Mechanisms & Limitations

1.  **Appointment:**
    *   Only the President can appoint or dismiss ministers.
    *   Command: `/dc cabinet appoint <position> <player>`
2.  **Costs & Cooldown:**
    *   Each decision costs money from the **National Treasury**.
    *   There is a cooldown between uses (Default: 48 Hours per minister).
3.  **Requirements:**
    *   The minister must be currently in office.
    *   The national treasury must have sufficient funds.
4.  **Automation:** Buffs are applied automatically when a player:
    *   Is inaugurated as an official.
    *   Logs into the server (Join Event).
    *   Respawns after death.
5.  **Removal:** Buffs are immediately removed if a player:
    *   Leaves office (Term ends/Impeached/Dismissed).
    *   Leaves the server (Quit Event).

## 🔧 Configuration
Cost and duration settings can be modified in `config.yml` under the `cabinet.decisions` node.

```yaml
cabinet:
  appointment-cooldown-days: 3
  daily-salary: 20000
  
  # Minister of Defense
  defense:
    prefix: "&4[MoD]"
    damage-multiplier: 1.12
    defense-multiplier: 1.10
    vault-multiplier: 1.15
    extra-hearts: 1.5
    daily-vault: 30000
    decision-cooldown-hours: 48
  
  # Minister of Treasury
  treasury-minister:
    prefix: "&2[MoT]"
    vault-multiplier: 1.25
    sell-bonus: 1.10
    buy-discount: 0.90
    daily-vault: 50000
    decision-cooldown-hours: 48
  
  # Minister of Commerce
  commerce:
    prefix: "&9[MoC]"
    vault-multiplier: 1.20
    rare-drop-bonus: 1.15
    daily-vault: 35000
    decision-cooldown-hours: 48
  
  # Minister of Infrastructure
  infrastructure:
    prefix: "&7[MoI]"
    vault-multiplier: 1.20
    claim-block-multiplier: 2.0
    daily-vault: 30000
    decision-cooldown-hours: 48
  
  # Minister of Culture
  culture:
    prefix: "&d[MoK]"
    xp-multiplier: 1.15
    vault-multiplier: 1.10
    afk-bypass: true
    daily-vault: 30000
    decision-cooldown-hours: 48
```
