# President System

This document explains the technical details of the President System module in the DemocracyCore plugin. This module handles the general election lifecycle, candidate requirements, voting mechanisms, and presidential inauguration.

## 📋 Overview

The President System is designed to simulate a realistic democratic process within the server. The election cycle runs automatically based on time configurations, dividing the process into several phases: Registration, Campaign, Voting, and Inauguration.

## 🔄 Election Cycle

The election process is managed by `ElectionManager` and is divided into 4 main phases (`ElectionPhase`):

### 1. Registration Phase (`REGISTRATION`)
*   **Duration:** 3 Days (Default, configurable).
*   **Activity:** Eligible players can register themselves.
*   **Command:** `/dc register [slogan]`
*   **Cost:** Candidates must pay a registration fee (Default: $500,000).
*   **Logic:** If no candidates register by the end of the phase, the registration phase will repeat.

### 2. Campaign Phase (`CAMPAIGN`)
*   **Duration:** 7 Days (Default).
*   **Activity:** Candidates promote themselves to gain support.
*   **Endorsement Feature:** Other players can provide official support (`Endorsement`) to candidates.
    *   Provides +10 Campaign Points per endorsement.
    *   Command: `/dc endorse <candidate_name>`
*   **Campaign Message:** Candidates can broadcast paid campaign messages with a specific *cooldown*.
    *   Broadcast Cost: $10,000.
    *   Cooldown: 6 Hours.

### 3. Voting Phase (`VOTING`)
*   **Duration:** 3 Days (Default).
*   **Activity:** Players cast votes for their chosen candidate.
*   **Command:** `/dc vote <candidate_name>`
*   **Reward System:**
    *   **Participation:** Every voter receives a monetary reward (Default: $10,000).
    *   **Lottery:** A number of lucky (random) voters receive an additional bonus (Default: $50,000 for 10 winners).

### 4. Inauguration Phase (`INAUGURATION`)
*   **Duration:** 1 Day (Default).
*   **Activity:** Final vote counting, winner announcement, and transfer of power.
*   **Refund:**
    *   The winner receives a 100% registration fee refund.
    *   Losers receive a 50% refund.

## 📜 Candidate Requirements

To register as president, players must meet strict criteria checked in `ElectionManager#meetsRequirements`:

| Criteria | Default Value | Description |
| :--- | :--- | :--- |
| **Minimum Level** | 100 | The player's XP level must reach this limit. |
| **Playtime** | 100 Hours | Total playtime recorded on the server. |
| **Balance** | $500,000 | Minimum balance required in the Vault account. |
| **Punishment History** | 30 Days | Must not have any punishment records (banned/muted) within this period. |
| **Term Limit** | 2 Terms | Cannot serve more than the consecutive term limit. |

## ⚖️ Weighted Voting Mechanism

This system does not use a pure *one-person-one-vote* rule. Player votes have different "weights" based on their contribution to the server.

**Formula:**
`Total Weight = Base Weight + Playtime Bonus + Level Bonus + Balance Bonus`

*   **Base Weight:** 1.0
*   **Playtime Bonus:** +0.5 (If playtime > 200 hours)
*   **Level Bonus:** +0.5 (If level > 75)
*   **Balance Bonus:** +0.5 (If balance > $1,000,000)
*   **Maximum Weight:** 2.5

*Note: The values above can be changed through configuration (`config.yml`).*

## 📚 President History & Data

Historical presidential data is stored in `PresidentHistory`. Every time a term ends (whether due to completion, impeachment, or resignation), a new record is saved.

**Stored data includes:**
*   UUID & President Name
*   Term Start & End Dates
*   Approval Rating (Public satisfaction level)
*   Number of Executive Orders issued
*   Number of Events held
*   List of Cabinet Members
*   Accomplishments
*   Reason for Leaving (Term End, Recall, Inactive, Admin Removal)

## ⚙️ Important Configurations

The following are the main configuration nodes in `config.yml` that govern this system:

```yaml
election:
  registration-days: 3
  campaign-days: 7
  voting-days: 3
  
  max-candidates: 3
  registration-fee: 500000
  
  registration-refund-winner: 1.0
  registration-refund-loser: 0.5
 
  voter-rewards:
    participation: 10000
    lottery-bonus: 50000
    lottery-winners: 10

  vote-weights:
    base: 1.0
    playtime-threshold-hours: 200
    playtime-bonus: 0.5
    level-threshold: 75
    level-bonus: 0.5
    balance-threshold: 1000000
    balance-bonus: 0.5
    max-weight: 2.5
```

## 🚨 Emergency Election Triggers

The system will trigger an automatic election if:
1.  The president's term has only 5 days remaining.
2.  There is no current serving president (Power vacuum).
3.  An admin manually triggers an emergency election.
